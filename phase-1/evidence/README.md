# Phase 1 Evidence Standard (Minimum)

Every Phase 1 run must include:

## Screenshots (>= 3, annotated)
1. Overall toolpath view
2. Close-up on layers / turns / transitions
3. Frames visible (TCP / WorkObject)

## Video (>= 1)
- Short screen recording showing multi-layer progression

## Naming (date-based)
Example:
- 2026-01-28_tg1_overall.png
- 2026-01-28_tg1_closeup.png
- 2026-01-28_tg1_frames.png
- 2026-01-28_tg1_multilayer.mp4

If these minimums are not met, the run is NOT complete.
