Sequence Diagram

ABB Online Simulation Platform — Full simulation pipeline from RAPID upload to 3D animation

Dynamic Behaviour 
sequenceDiagram
    actor Student
    participant FE as Frontend
Next.js
    participant API as FastAPI
Router
    participant RP as RapidParser
    participant RT as RapidTransformer
    participant TG as TrajectoryGenerator
    participant KS as KinematicsSolver
    participant CD as CollisionDetector
    participant PB as PyBullet
Engine

    Student->>FE: Upload .mod file
    FE->>API: POST /api/upload/rapid
    API->>RP: parse(code)
    RP->>RT: transform(parse_tree)
    RT-->>RP: Program (AST)
    RP-->>API: Program + errors/warnings
    API-->>FE: RapidUploadResponse (AST JSON)

    Student->>FE: Click Run Simulation
    FE->>API: POST /api/simulate
    Note right of API: Build Program from AST dict

    API->>TG: generate(program, robot_id)
    loop For each MoveCommand
        TG->>TG: _resolve_target()
        TG->>KS: inverse_kinematics(robot_id, target_pos)
        KS->>PB: calculateInverseKinematics()
        PB-->>KS: joint_angles
        KS-->>TG: joint_angles dict
        TG->>KS: forward_kinematics(robot_id, joints)
        KS->>PB: getLinkState()
        PB-->>KS: position + orientation
        KS-->>TG: TCP pose dict
        TG->>TG: Interpolate waypoints
    end
    TG-->>API: waypoints list + timed_out flag

    API->>CD: check_trajectory_collisions(robot_id, trajectory)
    loop For each waypoint
        CD->>PB: resetJointState()
        CD->>PB: performCollisionDetection()
        CD->>PB: getClosestPoints()
        PB-->>CD: contact_points
    end
    CD-->>API: collision results

    API->>API: Assemble SimulateResponse
    API-->>FE: SimulateResponse JSON
    FE->>FE: Animate in Babylon.js viewport
    FE-->>Student: 3D animation with collision highlights
