## 5. Collaboration Model (Support vs Mentorship)

Craig clarified that:

- ARIS is **not set up as a formal mentorship program**
- However, they have successfully supported applied research and capstone-style projects by:
  - Meeting approximately **once per week** (30–60 minutes)
  - Reviewing progress and blockers

  - Occasionally visiting student labs or hosting students at ARIS

The expectation is:

- **Student-led execution**
- **ARIS provides technical guidance and oversight**, not day-to-day supervision

## 7. Technical Expectations — Additive Manufacturing Project

For the **robotic additive manufacturing** project, ARIS clarified that work would involve:

- **RobotStudio + 3DP PowerPac**
- Programming in **RAPID**
- Converting **G-code generated by a slicer** into robot-executable code
- Running **simulations first**, followed by potential real-robot execution
- Understanding and working with:
  - **TCP calibration**
  - **WorkObject calibration**
  - Robot motion constraints

Importantly:

- The **G-code → RAPID conversion** was identified as a **strong match** for the students' software skill set
- There was discussion of **potentially improving or extending the slicer stage** (e.g., preprocessing, parameters, usability, output quality)
- It was explicitly acknowledged that:
  - The scope and weight of slicer improvements are **unknown**
  - This work is **optional / exploratory**, not a hard requirement
